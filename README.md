
# AI Business Intelligence Assistant

An AI-powered Business Intelligence application built using Python and Streamlit to automate business data cleaning, analysis, visualization, and reporting.

## Features

- Automated data cleaning
- Missing value detection
- Duplicate record detection
- KPI tracking and analysis
- Interactive Plotly visualizations
- AI-generated business insights
- Dynamic data filtering
- Automated PDF report generation

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- SQL

## Project Results

Processed business datasets containing 10,000+ records and automated data cleaning, KPI analysis, and report generation.

## Installation and Setup

1. Clone the repository:

   git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder.

3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py
